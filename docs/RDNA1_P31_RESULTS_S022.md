# S-022 — Offline Mesh IR-to-compute research proof

Selected subtask P3.1 only. `tests/research/MeshIrComputeLowering.{h,cpp}` accepts a non-owning view of real repository `IR::Block`, `IR::Inst`, `IR::Value`, `IR::ExportInfo` and `ShaderMeshInputInfo`, and emits SPIR-V assembly directly from IR instructions, assembled/validated for Vulkan 1.3 using SPIRV-Tools. `tests/MeshIrComputeTests.cpp` constructs public authored fixtures with the repository IREmitter. This is isolated research code, not wired to the emulator, renderer, decoder or native mesh emitter. No handwritten GLSL is used for the translation test.

Supported deliberately small subset: one complete straight-line block, one wave32 with 32 invocations, no LDS/scratch/split groups, triangle-list metadata, constant uniform `MeshAllocate` encoding either 0/0 or 3/1, and one full position-0 export plus one packed primitive export. Supported SSA: local-invocation index, U32/U1 immediates, compare, select, boolean and/or, four-component U32 construction and EXEC-mask operands. Allocated outputs must have mask coverage proved for every active output lane; packed indices must be in range and cull/reserved bits clear. Position float values are bit patterns carried through U32 IR. Compiled module writes the existing 1840-byte guarded output ABI (binding 1), uses bounded lane-dependent stores, a uniform workgroup barrier and lane-0 counts/reserved/Ok publication. It has GLCompute execution and no mesh extension or `OpSetMeshOutputsEXT`.

This is not full NGG translation. MeshDrawParameter, unresolved EXEC/M0/register operations, dynamic allocations, LDS/scratch, wave64, multi-block CFG, unsupported arithmetic, partial/auxiliary exports, culling, invalid indices and uncovered masks are explicitly rejected with empty output and diagnostics. The view must include all blocks; callers cannot safely pass a selected block from a larger program. The fixture is post-prologue synthetic IR, not decoded game shader code. Native defaults remain unchanged. The host lane evaluator proves coverage for this restricted finite input; it is not GPU execution.
