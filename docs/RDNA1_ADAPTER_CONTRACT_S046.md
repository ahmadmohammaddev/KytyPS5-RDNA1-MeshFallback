## Initial admission and rejection contract

Admission is a conjunction, not a heuristic on a shader hash. A pure selector returns ExistingGraphics for non-mesh, NativeMesh when genuinely enabled, precise Unsupported when no native path and opt-in is disabled/unavailable, and only ComputeCandidate when explicitly opted in and every coarse capability/draw bound is met. Candidate is not a compiled or renderable success: compiler/export/fragment/resource checks and prepared runtime pipeline bundle remain mandatory. Native stays preferred even when opt-in is present; no force-native-off mode in the first patch.

The first candidate needs Vulkan1.3 compute+graphics recording support, local size32x1x1 within actual compute limits and sufficient two/three storage-buffer bindings (depending on UV). U32/boolean finite lane computations do not require hardware subgroup32; the current IR metadata wave32 proof must be kept distinct from physical subgroup feature requirements. Live subgroup/wave/LDS/scratch/barrier semantics beyond the verified subset reject.

Reject unsupported guest topology, indexed/indirect/count/restart input, instance count other than1, first vertex/base/instance offsets, count other than3, multiple groups, nonzero first group, stage/tessellation mismatch, extra exports, unknown fragment interface, live resources, unsupported control flow, dynamic allocation/count, output capacities above ABI, cull/null/per-primitive attributes, clip/cull distance/user clip planes and unproven raster behavior. Compiler Lower remains the definitive instruction/coverage/type safety check. Unknown values require proof or reject; no default-false metadata field may assert support for an unexamined production state.

Baked draw parameters from the research specialization require either distinct compiled identities per context or validated fixed supported context. A future dynamic implementation must supply push data and re-prove address/bounds semantics; do not reuse a specialized binary with a different draw.

Guard/status buffers are a research ABI. For bounded production admission, counts and index validity must be proved before recording. If later shaders can overflow dynamically, no conventional draw may consume Pending/overflow data: require GPU-visible zero draw-count/indirect safety or explicit rejected execution design. A final status store alone cannot safely gate a draw.
